# 06 — Tracking & Tools

Set these up so you actually know whether the SEO work is working.

## Free tools to set up this week

### 1. Google Search Console (essential)
**What it does:** shows which keywords you rank for, click-through rates, technical errors, mobile issues, schema warnings.

Setup:
1. https://search.google.com/search-console
2. Click **Add property** → enter `https://taylorscollision.com`
3. Verify ownership (recommend the **HTML tag** method — paste a meta tag into `layout.tsx` — I can wire this in if you give me the verification code).
4. Once verified: **Sitemaps** → submit `https://taylorscollision.com/sitemap.xml`

Check weekly:
- **Performance** → see which queries you appear for, average position, CTR
- **Coverage / Pages** → confirm city pages are indexed
- **Enhancements** → confirm structured data is detected (LocalBusiness, FAQ)

### 2. Google Analytics 4 (essential)
**What it does:** how many people land on the site, from which sources, what they do.

Setup:
1. https://analytics.google.com → admin → create property
2. Add the GA4 measurement ID to the site (I can wire it in — give me the ID, looks like `G-XXXXXXXXXX`)
3. Connect GA4 to Search Console (admin → Property Settings → Search Console links) — combines both data sets.

Watch:
- **Reports → Acquisition → Traffic Acquisition** → how much is organic vs direct
- **Engagement → Pages and screens** → which city pages get traffic
- **Conversions** — track form submits + booking requests (event setup needed)

### 3. Bing Webmaster Tools
- https://www.bing.com/webmasters
- Submit same sitemap; takes 2 min.
- Bing/Yahoo carries ~10% of US searches and 30%+ of users 50+.

### 4. Google Business Profile Insights (free, in the GBP dashboard)
After verification:
- **Calls** from search → highest-intent metric
- **Direction requests** → ready-to-visit metric
- **Photo views** vs competitors → indicates relative visibility
- **Search queries** → what people searched to find you

## Optional paid tools (if you want pro tracking)

| Tool | Cost | Best for |
|---|---|---|
| **Local Falcon** | $25/mo | Grid view of your map-pack rank by ZIP — see where you do and don't show up |
| **BrightLocal** | $29/mo | Citation tracker + audit + reputation manager (review monitor) |
| **Semrush / Ahrefs** | $99–139/mo | Competitor keyword tracking, backlink analysis |
| **Whitespark** | $20+/mo | Local-specific rank tracker |

For a single-location body shop, **Local Falcon + free tools is usually plenty**. The others matter more if you have multiple locations or do serious SEO investment.

## A simple weekly dashboard (10 min)

Every Friday, check:

1. **GBP dashboard**
   - New reviews? Reply to each.
   - Calls this week vs last? (trend)
   - Posted this week? Post once if not.

2. **Search Console → Performance**
   - Total clicks this week vs last
   - Average position for "collision repair duluth" — is it moving up?
   - Any new queries showing impressions? (long-tail discovery)

3. **GA4 → Acquisition**
   - Organic-search sessions vs last week
   - Booking form completions

4. **Local Falcon** (if you set it up)
   - Run a fresh grid scan
   - Watch heat map move from red → green over months

## Setting realistic expectations

| Time after launch | What to expect |
|---|---|
| 2 weeks | GBP verified, city pages indexed, first organic clicks |
| 4–6 weeks | Showing up in long-tail searches ("collision repair suwanee", etc.) |
| 8–12 weeks | Climbing toward top 5 for `collision shop duluth` |
| 3–6 months | Top 3 in the Local Pack (assuming reviews keep flowing + citations consistent) |
| 12 months | Established. Lots of organic + map traffic; lower CPA than ads. |

Local SEO is a flywheel, not an event. Three months of consistent action beats one heroic week.

## When to call in help

You can DIY everything above. But if after **3 months** of consistent effort you're still not in the top 5 of the Local Pack:
- Hire a **local-only** SEO consultant (avoid big-promise agencies)
- Or one-off engagement for a citation cleanup (~$300) and audit (~$500–1000)
- Look for someone who can show you actual rank-graph results for similar businesses — not just talk.
